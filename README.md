### 项目梗概

#### **1. Data Manager 实现**

**核心目标**：整合服务层、缓存层、时效性处理和统一接口。

##### **1.1 Service 层实现**

- **功能**：模拟异步请求，返回 `booking.json` 数据。

##### **1.2 本地持久化缓存层**

- **策略**：使用 `localStorage` 存储数据及时间戳。

##### **1.3 时效性处理**

- **逻辑**：定义缓存有效期（如 30 分钟），超时则刷新。

##### **1.4 Data Manager 核心逻辑**

- **统一接口**：优先返回缓存，过期则自动刷新。

---

#### **2. 列表页面实现**

**目标**：每次页面展示时调用接口并打印数据。

##### **关键逻辑说明**

- **数据获取时机**：`useEffect` 在组件挂载时触发数据加载。
- **无缝展示**：优先展示缓存数据，后台静默刷新（可扩展为轮询或手动刷新按钮）。
